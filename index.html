📖 About

Kaspa P2P File Storageは、Kaspaブロックチェーンのトランザクションペイロードを使用して ファイルを永続的に保存する分散型ストレージシステムです。

主な機能:

  • ✅ ブロックチェーンへの永続的ファイル保存
  • 🔐 AES-256-GCM暗号化
  • 📦 効率的なチャンク管理
  • 🚀 並列ダウンロード対応
  • 📁 ディレクトリサポート（v4.3.0+）
